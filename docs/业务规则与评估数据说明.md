# MallMate 业务规则、模拟数据与评估说明

更新日期：2026-10-12

## 1. 本轮确定的范围

系统面向中国大陆电商售后演示场景。当前业务规则参考《消费者权益保护法》《网络购买商品七日无理由退货暂行办法》《电子商务法》和《消费者权益保护法实施条例》，再补充项目演示所需的流程规则。知识内容不代表某家真实平台承诺；接入真实商家时必须由业务和法务复核版本、有效期与适用商品范围。

当前固定 10 类意图：订单查询、物流查询、物流异常、退款、退货、换货、商品破损、少件漏发、错发和人工投诉。紧急度分为 `normal`、`medium`、`high`、`urgent`。

## 2. 业务规则如何保存

同一规则有两个表达层：

- `knowledge/policies/*.md`：面向用户解释和 RAG 检索，共 15 篇，包含稳定文档 ID、版本、分类和状态。
- `backend/app/domain/after_sales_policy.py`：面向程序执行资格判断，返回稳定决策码、是否需要凭证、是否需要人工和规则版本。

模型可以识别意图和抽取候选参数，但订单归属、售后资格、写入确认和幂等性由后端代码决定。知识文档中出现的指令不能改变系统权限。

演示规则包括：一般商品七日无理由退货；演示换货入口为签收后十五日；质量、少件和错发问题要求凭证；高价值申请进入人工审核；运输中订单先处理拦截或拒收；定制和鲜活易腐商品不能直接走普通无理由退货。质量问题不因“不适用无理由退货”而自动失去处理入口。

## 3. 模拟业务数据

`backend/fixtures/demo_data.json` 是版本化种子数据：

| 类型 | 数量 | 覆盖场景 |
|---|---:|---|
| 用户 | 3 | 普通、银卡、金卡演示账号 |
| 商品 | 8 | 家电、日用、数码、服饰、定制、生鲜、图书 |
| 订单 | 13 | 待处理、已支付、已发货、已签收、已完成、取消、退款完成 |
| 物流 | 9 | 运输中与已签收 |
| 已有售后单 | 2 | 已完成退款、等待凭证 |

启动种子程序会按稳定业务键补齐数据，并把 Markdown 文档导入 `knowledge_documents`。数据中的姓名、电话、订单、运单均为虚构内容。

修改 ORM 字段后，旧 SQLite 文件不会被 `create_all` 自动迁移。本轮目标环境已经确定为 PostgreSQL；首次使用新结构应使用空数据库启动。后续加入 Alembic 后通过迁移升级数据库，不能依赖删库重建。

## 4. 离线评估模块

评估入口是 `evals/runner.py`。它不启动 Agent、不连接数据库、不调用通义千问，确保没有 API Key 时也能验证：

1. **意图分类：**准确率、Macro-F1、各类别 Precision/Recall/F1 和紧急度准确率。
2. **知识检索：**BM25 基线的 Recall@5、MRR、NDCG@5。
3. **业务规则：**资格、决策码、凭证要求、人工要求四个字段完全匹配。

开发集含 40 条意图、24 条检索和 12 条规则数据；留出集含 20 条意图、12 条检索和 6 条规则数据。时间相关规则显式保存 `evaluation_time`，保证可复现。脚本输出 JSON 报告，未达到门槛时返回非零退出码。

当前数据是为验证管线而设计的合成数据，不能把结果写成真实线上准确率。真实阶段需要引入脱敏咨询，由两名标注者独立标注意图、相关文档、工具序列和业务结果，解决分歧后冻结版本。

## 5. 基础设施和模型约定

Docker Compose 包含 PostgreSQL、Redis、ChromaDB、MinIO、FastAPI、Next.js 和 Prometheus。持久卷都绑定到项目下 `data/`，位于 F 盘；本机 Docker Desktop 的 WSL 数据已位于 E 盘。

通义千问按职责分开配置：

| 职责 | 默认配置 |
|---|---|
| 对话生成 | `qwen-plus` |
| 意图识别 | `qwen-flash` |
| 图片理解 | `qwen-vl-plus` |
| 向量生成 | `text-embedding-v4` |
| 重排 | `qwen3-rerank` |

`QwenGateway` 只在 `MALLMATE_LLM_ENABLED=true` 且 Base URL、API Key 完整时创建客户端。当前默认关闭，因此本轮不会产生模型调用或费用。阿里云百炼的 API Key 与 Base URL 必须属于同一地域；工作空间地址和密钥由本机环境变量注入，不能提交 Git。

## 6. 当前尚未完成的能力

- Markdown 还没有切成可引用的知识片段，也没有写入 ChromaDB。
- 还没有 BM25 与向量召回的 RRF 融合、Query Rewrite 和重排。
- Redis、MinIO、ChromaDB 已配置容器与连接参数，业务适配器尚未接入流程。
- LangGraph 当前仍是单轮图，没有 checkpointer、暂停确认、工具注册、失败重试和人工工单。
- Prometheus 已能抓取 HTTP 数量与耗时；Agent 节点、工具、Token 和成本指标待补。
- 离线评估尚未重放多轮 Agent、数据库事务、越权、提示注入和工具故障。

这些内容按 `docs/30天开发计划.md` 继续实施。
