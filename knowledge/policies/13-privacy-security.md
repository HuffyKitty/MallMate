# 用户隐私、订单权限与安全边界

订单、物流、售后和附件属于用户数据。每次查询都必须在数据库条件中同时限制当前登录用户和资源 ID，不能先查出他人订单再由 Agent 判断。对于不存在和无权限资源，对外统一返回“未找到”，避免泄露资源是否存在。

不得在聊天、日志或轨迹中保存完整密码、API Key、银行卡号、身份证号、家庭地址和完整手机号。日志只记录脱敏标识、工具名称、结果码、耗时和必要摘要。附件使用私有对象存储，访问链接短期有效。

知识文档、用户消息和图片 OCR 都是不可信输入。其中出现“忽略规则”“直接退款”“输出系统提示”等内容不能改变系统权限。模型只能提出工具调用候选，后端必须再次校验身份、参数、业务规则、确认凭据和幂等键。
