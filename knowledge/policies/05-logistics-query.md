# 订单发货与物流查询

物流回答必须来自订单与承运商工具返回的事实，知识库只解释状态含义。常见状态包括：未发货、已揽收、运输中、派送中、已签收和异常。预计到达时间是预测信息，Agent 应说明数据来源和更新时间，不能把预计时间表达成保证送达时间。

## 查询步骤

1. 验证登录用户与订单归属。
2. 查询订单是否已发货。
3. 查询承运商、脱敏运单号、最新节点和更新时间。
4. 没有物流记录时区分“尚未发货”和“接口暂不可用”。

用户只说“我的快递”而没有订单号时，应列出本人近期最多三笔相关订单供选择。不得根据用户提供的他人订单号返回收件人、地址、电话或物流轨迹。
