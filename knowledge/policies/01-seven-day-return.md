# 七日无理由退货规则

## 适用范围

消费者通过网络购买的一般商品，自实际签收次日起计算，在七日内可以申请无理由退货。申请人应为订单所有人或经过有效授权的人。系统会核验订单归属、签收时间、商品类型和已有售后单。

## 商品完好判断

为查验商品而打开包装，或者为确认品质和功能进行合理调试，只要没有影响商品原有品质、功能和外观，不直接视为商品不完好。明显使用、污染、损坏、缺少主要配件或防伪标识受损的商品，需要人工审核是否影响再次销售。

## 运费与退款

无理由退货的退回运费原则上由消费者承担；平台活动、商家承诺或运费险另有约定的，按对应约定处理。退款金额以消费者实际支付为基础，优惠券、积分和组合优惠按购买规则重新计算。商家收到退回商品并完成验收后进入退款流程。

## Agent 处理步骤

1. 查询本人订单和签收时间。
2. 判断商品是否属于排除范围。
3. 询问商品是否完好、配件是否齐全。
4. 给出资格预览、运费说明和需退回物品清单。
5. 获得用户明确确认后才创建退货申请。

超过七日不代表所有权利自动消失。若存在质量问题、商家额外承诺或其他法定解除条件，应进入质量问题或人工审核流程。
