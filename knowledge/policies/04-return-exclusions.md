# 不适用无理由退货的商品

以下类别通常不适用七日无理由退货：消费者定作的商品；鲜活易腐商品；在线下载或已拆封的音像制品、计算机软件等数字化商品；已交付的报纸、期刊。其他因商品性质不宜退货的商品，必须在购买必要流程中被显著提示并由消费者确认，不能把“不支持退货”设为默认同意。

演示数据中的刻字纪念杯属于定制商品，冷藏蛋糕属于鲜活易腐商品，因此普通无理由退货会转人工核验。

“不适用无理由退货”不等于出现质量问题也不能售后。商品有质量缺陷、错发、少件、运输损坏或与宣传明显不符时，应进入相应责任处理流程。Agent 回答时必须说明拒绝的是哪一种申请依据，不能笼统回复“特殊商品一律不退”。
